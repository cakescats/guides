# CakesCats guides

**Free, open setup guides for every CakesCats product.** CakesCats is a non-profit project: everything we sell ready-made can be built yourself for free with these guides. Buying a ready device or individual support from us is how you support the project.

**Бесплатные открытые инструкции по настройке всех продуктов CakesCats.** CakesCats — некоммерческий проект: всё, что мы продаём готовым, можно собрать самому бесплатно по этим инструкциям. Купить готовое устройство или индивидуальную поддержку — значит поддержать проект.
