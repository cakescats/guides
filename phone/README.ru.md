## 1. Какой телефон подойдёт

- **Google Pixel 8 и новее** (Pixel 8/8a/9/9a/10, Pro, Fold). У них самый долгий срок обновлений безопасности. Актуальный список — [grapheneos.org/faq#supported-devices](https://grapheneos.org/faq#supported-devices).
- Телефон должен быть **разблокирован у оператора**. Модели, привязанные к оператору (например, некоторые американские), не дают разблокировать загрузчик.
- Перенесите с телефона всё нужное: установка **стирает все данные**.

## 2. Подготовка

На телефоне со стоковым Android:

1. Подключитесь к интернету и обновите систему.
2. **Настройки → О телефоне** → 7 раз нажмите **Номер сборки** — включатся параметры разработчика.
3. **Настройки → Система → Для разработчиков** → включите **Разблокировка OEM** (OEM unlocking).
4. Выключите телефон.

На компьютере:

- **Windows:** установите [Google USB Driver](https://developer.android.com/studio/run/win-usb).
- **Linux:** установите пакет `android-sdk-platform-tools-common` (правила udev), на время установки остановите `fwupd`.
- **macOS:** ничего не нужно.

## 3. Установка GrapheneOS

Используйте официальный веб-установщик: **[grapheneos.org/install/web](https://grapheneos.org/install/web)**. Не скачивайте GrapheneOS ни из каких других мест.

1. Зажмите **Питание + Громкость вниз** — телефон загрузится в режим загрузчика (fastboot). Подключите кабель.
2. На странице установщика нажмите **Unlock bootloader**. На телефоне кнопками громкости выберите *Unlock the bootloader* и подтвердите кнопкой питания.
3. **Download release** — дождитесь загрузки.
4. **Flash release** — не трогайте телефон и кабель до конца.
5. **Lock bootloader** — подтвердите блокировку на телефоне так же кнопками. **Это обязательно:** без блокировки защита проверенной загрузки не работает.
6. Нажмите кнопку питания на пункте *Start* — запустится GrapheneOS.

## 4. Проверяем, что всё подлинное

- При каждом включении телефон показывает жёлтое предупреждение *«Your device is loading a different operating system»* и **отпечаток ключа**. Сверьте его со списком на странице [установщика](https://grapheneos.org/install/web#verifying-installation). Совпадает — система подлинная.
- После первой настройки отключите **Разблокировку OEM**: **Настройки → Система → Для разработчиков** (включаются так же, 7 нажатий на номер сборки).
- По желанию: приложение **Auditor** (уже есть в системе) позволяет периодически проверять телефон с помощью второго устройства через аппаратную аттестацию. Инструкция — [attestation.app/tutorial](https://attestation.app/tutorial).

## 5. Первые настройки безопасности

Пройдите мастер настройки **без входа в какие-либо аккаунты**. Затем:

| Что | Где | Как настроить |
|---|---|---|
| Блокировка экрана | Настройки → Безопасность и конфиденциальность → Разблокировка устройства | **PIN из 6+ цифр** или пароль. Графический ключ не используйте |
| Перемешивание цифр PIN | Там же → настройки блокировки экрана | **Scramble PIN input layout** — включить (по следам на экране PIN не подсмотреть) |
| Автоперезагрузка | Настройки → Безопасность и конфиденциальность → Защита от эксплойтов → **Auto reboot** | По умолчанию 18 часов, можно поставить 8–12. После перезагрузки данные снова полностью зашифрованы |
| Порт USB-C | Там же → **USB-C port** | **Charging-only when locked** — когда телефон заблокирован, порт только заряжает. Вариант строже — **Charging-only** |
| Wi-Fi и Bluetooth | Настройки → Сеть → Интернет / Bluetooth | Включите автоматическое выключение, когда к ним ничего не подключено |
| Обновления | Настройки → Система → Обновление системы | Оставьте автоматические, перезагружайтесь при напоминании |

## 6. Экстренная очистка (Duress PIN)

Отдельный PIN-код, ввод которого **мгновенно и необратимо стирает телефон**, включая все профили и eSIM.

1. **Настройки → Безопасность и конфиденциальность → Разблокировка устройства → Duress Password**.
2. Задайте **Duress PIN** (для экрана с PIN) и **Duress password** (если пользуетесь паролем).
3. Он должен отличаться от основного PIN и быть запоминающимся.

Работает везде, где система спрашивает PIN: на экране блокировки и в любых запросах подтверждения. Стирание не требует перезагрузки и его нельзя прервать.

> ⚠️ **Не проверяйте Duress PIN на телефоне с данными** — он действительно всё сотрёт. Держите резервные копии важного (раздел 10).

## 7. Изолированные профили

Каждый профиль — отдельный «телефон в телефоне» со своими приложениями, данными и ключами шифрования.

1. **Настройки → Система → Несколько пользователей** → включите → **Добавить пользователя**.
2. Создайте, например:
   - **«Работа»** — рабочие мессенджеры и почта;
   - **«Крипто»** — только кошелёк (см. ниже);
   - основной профиль (Owner) — личное.
3. Для каждого профиля задайте свой PIN.
4. Переключение — через быструю панель (значок пользователя). Закончили работу в профиле — нажмите **End session** (завершить сеанс): ключи профиля выгружаются из памяти, и до следующего ввода PIN его данные полностью зашифрованы.
5. Чтобы получать уведомления из других профилей: **Настройки → Система → Несколько пользователей** → **Send notifications to current user**.

**Профиль «Крипто»:**
- Ставьте только кошелёк из официального источника (сайт разработчика или GitHub через Obtainium) либо приложение-компаньон вашего аппаратного кошелька.
- Всем остальным приложениям в профиле отключите разрешение **Сеть**.
- **Сид-фразу никогда не храните в телефоне:** только на бумаге или металле, отдельно.

## 8. Приложения

В GrapheneOS есть собственный **App Store** с системными приложениями: браузер Vanadium, камера, просмотрщик PDF, Auditor. Через него же можно поставить **Accrescent** — магазин приложений с проверкой подписи.

Рекомендуемые приложения (ставьте из официальных источников: Accrescent или [Obtainium](https://github.com/ImranR98/Obtainium), который скачивает напрямую с сайта или GitHub разработчика):

| Задача | Приложение |
|---|---|
| Сообщения и звонки | Signal или Molly |
| Пароли | KeePassDX или Bitwarden |
| Двухфакторные коды | Aegis Authenticator |
| Почта | Proton Mail или Tuta |
| Карты без слежки | Organic Maps |
| Браузер | Vanadium (уже установлен) |

**Если без сервисов Google не работает какое-то приложение** (банк, такси): App Store → **Sandboxed Google Play**. Ставьте его **в отдельный профиль**: там Google Play работает как обычное приложение в песочнице, без особых прав, и ничего не видит за пределами профиля.

Ещё две полезные функции GrapheneOS, которые настраиваются при выдаче разрешений:
- **Storage Scopes** — приложение видит только те файлы, которые вы ему дали;
- **Contact Scopes** — приложение видит только выбранные контакты.

## 9. Сеть и VPN

**Разрешение «Сеть»** есть только в GrapheneOS. Его можно снять с любого приложения, и оно вообще не выйдет в интернет:
- при установке приложения — переключатель **Сеть**;
- для уже установленного: долгое нажатие на значок → **О приложении → Разрешения → Сеть**.

Там же есть разрешение **Датчики** (акселерометр и другие) — его тоже можно отключать.

**VPN для всего телефона:**
1. Установите клиент вашего VPN. Для WireGuard — приложение WireGuard; для сервера V2Ray/Xray, например нашего VPN-роутера, — клиент с поддержкой VLESS (например, v2rayNG через Obtainium).
2. **Настройки → Сеть и интернет → VPN** → значок ⚙ рядом с VPN → включите **Постоянный VPN** и **Блокировать соединения без VPN**. Теперь при отключении VPN телефон не выходит в интернет напрямую.

## 10. Резервные копии

- **Настройки → Система → Резервное копирование** (Seedvault): зашифрованная копия на USB-флешку или в облако. **Код восстановления из 12 слов** запишите на бумаге.
- Пароли и 2FA храните в KeePassDX или Bitwarden с отдельной резервной копией.
- Сид-фразы — только офлайн.
