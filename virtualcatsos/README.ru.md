# VirtualCatsOS: приватная рабочая среда на Mac (Apple silicon)

[English version](README.md)

Это пошаговая инструкция, по которой можно бесплатно собрать то же, что мы ставим клиентам. Получится:

- **виртуальная машина Ubuntu (ARM64) в UTM**: всё, что вы делаете внутри, отделено от macOS;
- **весь сетевой трафик виртуальной машины идёт через Tor**, а если Tor не работает, интернета в ней просто нет (утечки в обход невозможны);
- **машина хранится в зашифрованном контейнере VeraCrypt со скрытым томом («двойным дном»)**. Есть внешний том с обычными файлами и скрытый том, о существовании которого нельзя узнать без второго пароля.

Время: 1,5–2 часа. Нужен Mac на Apple M1 или новее, лучше с 16 ГБ памяти, и около 80 ГБ свободного места.

> Не хотите настраивать сами? Мы сделаем это за вас и будем поддерживать — см. [os.cakescats.com](https://os.cakescats.com/ru/). Это и есть способ поддержать наш некоммерческий проект.

## 1. Что важно понимать заранее

- **Это не волшебная кнопка.** Среда защищает от слежки со стороны macOS, от утечки вашего IP-адреса и от того, что кто-то, получив ваш Mac, увидит содержимое машины. Она не защитит, если вы сами войдёте в личные аккаунты внутри среды или на Mac стоит шпионская программа, которая снимает экран и клавиатуру.
- **Скрытый том работает, только если соблюдать правила** из раздела 9. Иначе его можно случайно повредить или выдать.
- **Пароли не восстанавливаются.** Забыли пароль — данные потеряны. Запишите пароли на бумаге и храните отдельно от Mac.
- Соблюдайте законы своей страны.

## 3. Контейнер VeraCrypt со скрытым томом

Установите FUSE-T, затем VeraCrypt. При первом запуске macOS попросит разрешения в «Системные настройки → Конфиденциальность и безопасность» — разрешите.

### 3.1. Создаём контейнер

1. VeraCrypt → **Create Volume** → **Create an encrypted file container** → **Hidden VeraCrypt volume** → **Normal mode**.
2. Расположение: например, `~/Documents/archive.hc`. Имя файла лучше скучное.
3. **Внешний том (outer volume):** алгоритм AES, размер — **120 ГБ** (виртуальной машине нужно ~60 ГБ в скрытом томе плюс место под обычные файлы во внешнем).
4. Пароль внешнего тома — **пароль №1** («для показа»). Длинный, но не такой, как у скрытого.
5. Файловая система внешнего тома: **exFAT**.
6. Двигайте мышью внутри окна, пока полоса не заполнится, затем **Format**.
7. VeraCrypt откроет внешний том. **Скопируйте туда правдоподобные, но не важные файлы**: документы, фото, PDF. Это «первое дно».
8. **Скрытый том (hidden volume):** размер — **65 ГБ** (VeraCrypt покажет максимум), файловая система — **Mac OS Extended**, пароль — **пароль №2** (главный, отличается от №1).
9. Готово. Нажмите **Dismount All**.

### 3.2. Как это работает

- Ввели **пароль №1** — открывается внешний том с обычными файлами.
- Ввели **пароль №2** — открывается скрытый том с виртуальной машиной.
- Снаружи файл `archive.hc` выглядит как случайные данные. Доказать, что внутри есть второй том, нельзя.

### 3.3. Убираем следы в macOS

Смонтируйте скрытый том (пароль №2). Допустим, он появился как `/Volumes/NO NAME`. Затем:

```bash
sudo mdutil -i off "/Volumes/NO NAME"      # Spotlight не индексирует том
sudo tmutil addexclusion ~/Documents/archive.hc   # Time Machine не копирует контейнер
```

## 4. Виртуальная машина в UTM

1. UTM → **+** → **Virtualize** → **Linux**.
2. Память: **8 ГБ** (если у Mac 8 ГБ — поставьте 4 ГБ). Ядра: **4**.
3. Boot ISO Image: выберите скачанный образ Ubuntu.
4. Диск: **48 ГБ**. Общие папки: **не добавлять**.
5. Имя: что-нибудь нейтральное, например `work`. **Save**.
6. **Перенесите машину в скрытый том.** Правый клик по машине → **Show in Finder**. Закройте UTM, перетащите файл `work.utm` в смонтированный скрытый том, удалите оригинал. Откройте UTM → **File → Open** → выберите `work.utm` в скрытом томе.
7. Настройки машины (правый клик → **Edit**):
   - **Sharing → Clipboard Sharing: выключить** (буфер обмена Mac и машины не смешивается);
   - **Network → Network Mode: Shared Network**.

## 5. Установка Ubuntu

Запустите машину и пройдите установщик:

1. Язык — любой. Раскладка — ваша.
2. Тип установки — **Ubuntu Server (minimized)** можно не выбирать, обычный вариант подходит.
3. Сеть — оставьте как есть (DHCP).
4. Диск — **Use an entire disk**. Галочку **Set up this disk as an LVM group** оставьте; **Encrypt the LVM group with LUKS** — по желанию (второй слой шифрования).
5. Имя пользователя и имя компьютера — **не настоящие** (например, `user` и `workstation`).
6. **Install OpenSSH server** — не нужно. **Import SSH identity** — нет. Дополнительные снапы — не выбирать.
7. После установки: **Reboot Now**. Если машина снова загрузится в установщик — выключите её, в настройках UTM очистите поле CD/DVD и включите снова.

Войдите и поставьте графическую оболочку:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y ubuntu-desktop-minimal spice-vdagent
sudo reboot
```

## 6. Настройки приватности Ubuntu

Откройте Терминал в Ubuntu и выполните:

```bash
# Удаляем отправку отчётов и статистики
sudo apt purge -y ubuntu-report popularity-contest apport whoopsie 2>/dev/null
sudo apt autoremove -y

# Отключаем «новости» при входе
sudo sed -i 's/^ENABLED=1/ENABLED=0/' /etc/default/motd-news 2>/dev/null
sudo systemctl disable --now motd-news.timer 2>/dev/null

# Брандмауэр: входящие соединения запрещены
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable

# Автоматические обновления безопасности
sudo apt install -y unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades
```

В **Настройках Ubuntu**:

- **Конфиденциальность → Местоположение**: выключить.
- **Конфиденциальность → Диагностика**: «Никогда».
- **Конфиденциальность → История файлов**: выключить и очистить.
- **Питание → Экран блокируется**: через 5 минут; **Блокировка экрана**: включена.

## 7. Весь трафик через Tor

Ставим Tor и настраиваем «прозрачный» режим: любая программа в машине выходит в интернет только через Tor. Если Tor остановлен, интернета нет.

```bash
sudo apt install -y tor nftables
```

Добавьте настройки Tor:

```bash
sudo tee -a /etc/tor/torrc >/dev/null <<'EOF'

# --- VirtualCatsOS: прозрачный режим ---
VirtualAddrNetworkIPv4 10.192.0.0/10
AutomapHostsOnResolve 1
TransPort 127.0.0.1:9040
DNSPort 127.0.0.1:5353
EOF
sudo systemctl restart tor
```

Правила сети (весь TCP и DNS — в Tor, всё остальное — запрещено, IPv6 — запрещён):

```bash
sudo tee /etc/nftables.conf >/dev/null <<'EOF'
#!/usr/sbin/nft -f
flush ruleset

table ip torify {
  chain nat_out {
    type nat hook output priority -100; policy accept;
    meta skuid "debian-tor" return
    ip daddr 127.0.0.0/8 return
    udp dport 53 redirect to :5353
    tcp flags & (fin|syn|rst|ack) == syn redirect to :9040
  }
  chain filter_out {
    type filter hook output priority 0; policy drop;
    oifname "lo" accept
    meta skuid "debian-tor" accept
    ct state established,related accept
    udp dport 67 accept
  }
}

table ip6 noipv6 {
  chain filter_out {
    type filter hook output priority 0; policy drop;
    oifname "lo" accept
  }
}
EOF
sudo systemctl enable --now nftables
```

DNS машины должен смотреть на Tor:

```bash
sudo mkdir -p /etc/systemd/resolved.conf.d
printf '[Resolve]\nDNS=127.0.0.1:5353\nDNSStubListener=yes\nDomains=~.\n' | sudo tee /etc/systemd/resolved.conf.d/tor.conf
sudo systemctl restart systemd-resolved
```

**Проверка:**

```bash
curl -s https://check.torproject.org/api/ip
```

Должно быть `"IsTor":true`. Для проверки «аварийного выключателя» остановите Tor (`sudo systemctl stop tor`) и повторите команду: ответа быть не должно. Затем `sudo systemctl start tor`.

> Синхронизация времени через интернет в этом режиме не работает. Время машина берёт у Mac, этого достаточно. Если Tor ругается на время, перезагрузите машину.

## 8. Браузер

Официального Tor Browser для Linux на ARM64 пока нет (есть только ночные сборки). Поэтому:

- **Firefox** (уже установлен) — весь его трафик и так идёт через Tor на уровне системы. Настройки → **Конфиденциальность и защита** → режим **Строгий**, **Удалять куки и данные сайтов при закрытии** — включить, **Отправлять сайтам сигнал «Не отслеживать»** — включить, телеметрию Firefox — выключить. В `about:config` установите `privacy.resistFingerprinting = true`.
- **Не входите в личные аккаунты** (почта, соцсети), которыми пользуетесь вне этой среды. Иначе приватность теряет смысл.
- Когда Tor Project выпустит стабильный Tor Browser для ARM64 Linux — ставьте его.

## 9. Как пользоваться каждый день

**Начать работу:**
1. VeraCrypt → выберите `archive.hc` → **Mount** → **пароль №2** (скрытый том).
2. UTM → запустите машину `work`.

**Закончить работу:**
1. Выключите Ubuntu (меню → Выключить).
2. Закройте UTM.
3. VeraCrypt → **Dismount All**.

**Правила для «двойного дна»:**
- Время от времени монтируйте **внешний** том (пароль №1) и меняйте там файлы, чтобы он выглядел живым.
- **Перед записью во внешний том** включайте защиту скрытого тома: VeraCrypt → **Mount** → **Mount Options** → **Protect hidden volume against damage** → введите **пароль №2**. Без этого запись во внешний том может стереть скрытый.
- Никогда не держите копию `work.utm` вне скрытого тома.
- Не делайте резервные копии контейнера разными версиями: сравнение двух копий может выдать, что меняется «пустое» место.

## 10. Если что-то пошло не так

| Проблема | Решение |
|---|---|
| В машине нет интернета | `sudo systemctl status tor` — Tor должен быть `active`. Подождите минуту после включения машины. |
| Нужно временно выключить режим Tor | `sudo systemctl stop nftables` (интернет пойдёт напрямую!). Вернуть: `sudo systemctl start nftables`. |
| VeraCrypt не монтирует том | Проверьте, что установлен FUSE-T и разрешён в «Конфиденциальность и безопасность». |
| UTM не видит машину после переноса | UTM → File → Open → выберите `work.utm` в смонтированном скрытом томе. |
| Мало места в скрытом томе | Создайте контейнер побольше и перенесите `work.utm`. Увеличить существующий скрытый том нельзя. |
